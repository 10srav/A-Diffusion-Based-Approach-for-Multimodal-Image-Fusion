# Sample Data Directory

Place your infrared and visible image pairs here for testing.

## Expected Format

- Images should be in PNG or JPEG format
- Recommended resolution: 512×512 (will be resized automatically)
- Infrared images can be grayscale or RGB

## Sample Datasets

You can download sample images from:

1. **RoadScene Dataset**: Traffic scenes with IR/VIS pairs
2. **MSRS Dataset**: Multi-Spectral Road Scenes
3. **FMB Dataset**: Full-time Multi-modality Benchmark

## Naming Convention

```
sample_vis.png   # Visible image
sample_ir.png    # Infrared image
```
